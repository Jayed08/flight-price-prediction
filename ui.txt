Font

I'd use IBM Plex Sans.

It has a more technical/data-science feel than the very common Inter/Poppins combination.

Use:

IBM Plex Sans → UI and headings
IBM Plex Mono → metrics / model numbers if you want a technical touch

For example:

Flight Price Prediction

in IBM Plex Sans SemiBold rather than the current very heavy Streamlit-looking heading.

Avoid:

Poppins
Montserrat
Roboto + Inter combinations
futuristic fonts

They tend to make the application look more like a generic AI SaaS landing page.

7. SHAP chart

For SHAP, keep the standard SHAP red/blue semantics because those colors actually carry meaning:

red → high feature value
blue → low feature value

Don't arbitrarily replace those.

But change the surrounding plot background and text to match your application.

So:

Native feature importance: amber
SHAP: standard red/blue
Residual plot: neutral/amber
Predicted vs actual: neutral/amber

That gives the app a coherent system without destroying the meaning of SHAP.

9. Don't over-round everything

Your current UI has a lot of rounded rectangles.

I'd reduce the border radius.

Use approximately:

border-radius: 6px;

instead of very rounded cards.

This is another subtle but significant difference.

AI SaaS aesthetic: 16px–24px rounded cards
Technical application: 4px–8px restrained corners

For your project, I'd choose 6px.

10. Exact CSS direction

You can put something along these lines into your Streamlit CSS:

<style>

@import url('https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@400;500&family=IBM+Plex+Sans:wght@400;500;600;700&display=swap');

html, body, [class*="css"] {
    font-family: 'IBM Plex Sans', sans-serif;
}

.stApp {
    background-color: #111315;
    color: #E8E6E1;
}

section[data-testid="stSidebar"] {
    background-color: #17191C;
    border-right: 1px solid #34383D;
}

h1, h2, h3 {
    font-family: 'IBM Plex Sans', sans-serif;
    font-weight: 600;
    letter-spacing: -0.02em;
}

.stButton > button {
    background-color: #D6A84F;
    color: #111315;
    border: none;
    border-radius: 6px;
    font-weight: 600;
}

.stButton > button:hover {
    background-color: #E0B866;
}

div[data-testid="stMetric"] {
    background-color: #1D2023;
    border: 1px solid #34383D;
    border-radius: 6px;
    padding: 12px;
}

</style>

You can then refine the exact Streamlit selectors based on your current app.
